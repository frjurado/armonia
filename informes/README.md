# Informes

Registro fechado de hitos y decisiones de diseño y desarrollo (apuntes y app), para que
no se pierdan entre commits.

- **Un informe no se reescribe.** Si una decisión cambia, se escribe otro informe y se
  actualizan los documentos vigentes (`curriculum/`, `app/docs/`, `apuntes/`), que son los
  que describen el estado actual.
- **Un fichero por hito**: `AAAA-MM-DD-tema.md`, con contexto, decisiones (y su motivo),
  plan o consecuencias.
- **`HISTORIA.md`** es el resumen de fondo del desarrollo, por fases; se pone al día al
  añadir un informe que cierre o abra una fase.
- No se publica en el sitio.
