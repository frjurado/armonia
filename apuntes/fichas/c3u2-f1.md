> Apuntes c3u2 §1 (I–V–I en estado fundamental, la cadencia como contraste,
> escritura y conducción). Solo I y V, sin 7.ª, en estado fundamental y
> alternados; el bajo, ① y ⑤; la soprano, por grado en 7̂ 1̂ 2̂ 3̂. Las
> realizaciones son las del núcleo de la app (tonica-dominante-core.js),
> que enumera todas las válidas y elige por lo que ceden; comprobadas con
> los mínimos de 3.º UD 2 y la licencia N11I.
>
> Ejercicio 1, como Estado fundamental › Bajo dado: el bajo y el primer
> acorde; la realización obvia (nota común, las demás por grado, la
> sensible a la tónica) es única.
> a) Sol mayor, I–V–I, soprano 3̂–2̂–3̂. b) Re menor, V–I, soprano 2̂–3̂.
>
> Ejercicio 2, como Estado fundamental › Canto dado (niveles 1 y 2):
> a) La menor, 1̂–7̂–1̂: realización obvia.
> b) Do mayor, 3̂–2̂–1̂: con 2̂–1̂ no cabe la obvia. La solución impresa deja
>    el último I sin 5.ª (fundamental triplicada; la contralto salta Sol–Mi
>    para dar la 3.ª). También vale con la sensible en la contralto, que
>    baja a 5̂ bajo el 1̂ de la soprano: S Mi–Re–Do, A Do–Si–Sol,
>    T Sol–Sol–Mi, B Do–Sol–Do (el tenor salta Sol–Mi).
>
> Ejercicio 3, como Estado fundamental › Cadencia:
> a) Do mayor, CA de tres acordes: I–V–I; la impresa, con la soprano
>    1̂–7̂–1̂, es CAP (con 3̂–2̂–3̂ sería CAI).
> b) Re menor, SC de dos acordes: I–V.

```lilypond
  \key d \minor s2*2 \bar "|."

  \rotuloAnalisis "b) Re menor" "b) Re menor" e'2 \analitico { f'2 }
}
contralto = { d'2 \analitico { d'2 d' } cs'2 \analitico { d'2 } }
tenor     = { g2 \analitico { fs2 g } a2 \analitico { a2 } }

  \acorde "I" g,2 \acorde "V" d \acorde "I" g, |
  \acorde "V" a, \acorde "I" d
}
```
